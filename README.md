# Muhammad Junaid — Developer Portfolio (React & Vite)

A modern developer portfolio website built with React 18, Vite, and Tailwind CSS to showcase software projects, experience, and contact details.

## What It Includes

- **Hero & Bio**: Introduction header highlighting software engineering experience and background.
- **Projects Showcase**: Interactive gallery of engineering projects with live demos and source code links.
- **Experience & Skills**: Detailed technical stack breakdown and timeline cards.
- **Contact Form**: Interactive contact form with input validation.
- **Navigation & UX**: Responsive navbar with mobile menu, smooth scrolling, and scroll-to-top floating action.

## Tech Stack

- **React 18**
- **Vite 4**
- **Tailwind CSS 3**
- **React Icons**

## How to Run It Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/iamjunaidjutt/my-site.git
   cd my-site
   ```
2. Install dependencies:
   ```bash
   yarn install
   # or: npm install
   ```
3. Start development server:
   ```bash
   yarn dev
   # or: npm run dev
   ```
4. Open the displayed local URL (typically `http://localhost:5173`) in your browser.
